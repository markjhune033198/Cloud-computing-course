Cloud Concepts Reflection
 
Cloud computing has long been part of my daily life, even before I fully understood how it works. Three services I use regularly are Google Drive, Canva, and GCash. Google Drive lets me store and access school files anywhere; it is Software as a Service (SaaS) since I only use the finished tool without managing servers, and runs on a Public Cloud shared by other users. Canva is also SaaS, giving me access to design tools directly through my browser, hosted on a public cloud. GCash is SaaS as well, but uses a Hybrid Cloud: public cloud for easy access, and private cloud to keep financial data secure.
 
Learning about version control showed me how important it is for cloud work. Cloud setups have many connected parts, and changing one can break the whole system. Git and GitHub keep a full history of changes, so we can easily go back to an older working version if mistakes happen. It also lets teams work together smoothly, review updates before applying them, and avoid overwriting each other’s work.
 
Overall, this lesson helped me see cloud services not just as useful tools, but as structured systems that rely on clear models and good practices to stay safe and reliable.
