## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest overall range of cloud services among the three major providers. It provides a very large ecosystem covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other specialized services.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works particularly well with Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in Artificial Intelligence, Machine Learning, and Kubernetes. Its AI infrastructure and Google Kubernetes Engine make it a strong platform for organizations developing modern AI and containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad range of services and has a mature cloud ecosystem. It also provides many opportunities to learn different areas of cloud computing and can support applications ranging from small projects to large enterprise systems.
